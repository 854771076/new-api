# 07: 管理员控制 App 展示，并提供应用广场入口

**What to build:** 管理员在现有 App 配置中开启广场展示、填写简介与访问地址并调整顺序，用户从站点导航进入应用广场，看到可用子产品并打开访问。

**Blocked by:** None (can start immediately)

**Status:** draft — 待确认拆分及 tracker 后，以 ready-for-agent 发布

- [ ] 新旧 App 的广场展示开关默认关闭；名称/图标复用，新增简介、独立 HTTPS 访问地址和排序，表单沿用现有组件。
- [ ] 访问地址与 OAuth 回调分别保存、分别校验；非法协议、脚本 URL 与不安全外链被拒绝。
- [ ] 服务端公共列表仅返回展示开启且启用的 App，稳定排序；DTO 仅含公开展示字段，不泄露管理配置、secret、Key、用户及资产。
- [ ] 导航入口可达，卡片包含名称、图标、简介和打开按钮；使用现有卡片、加载/错误/空状态及安全外链方式。
- [ ] 隐藏仅改变广场可见性，不注销既有用户关系，不影响钱包、订阅或 Key；停用与隐藏语义明确区分。
- [ ] 保留全部现有 new-api 与 QuantumNous 品牌及归属，不把新广场做成品牌替换。
- [ ] 覆盖默认隐藏、公开/隐藏切换、停用、非法地址、稳定排序、空列表和秘密不出现在响应中的 HTTP/浏览器回归；七语言、键盘和移动端可用。
- [ ] 新字段迁移在真实三数据库验证空库、发布版升级与两次启动；适用前端检查、构建和基线审计通过。

验收证据对应 checklist E01—E05。广场不承担 SSO、财务授权或运营推荐功能，因此不依赖其他 tickets。
