11. **后台财务范围与筛选**。Blocked by：01、05。交付：独立筛选全部授权可管理 App，积分、用户、套餐及订单操作不串范围。
12. **Supabase 参考接入**。Blocked by：02、03、05、06。交付：独立代理用户完成 Key、余额、报价、AI 和充值/订单，不关联 OAuth 用户、不支持订阅，不等控制台 UI，skill/starter/公开合同同步。
