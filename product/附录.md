## 1. 术语表

| 术语 | 含义 |
| --- | --- |
| **渠道（Channel）** | 一个已配置的上游供应商连接，含密钥、模型列表、优先级、权重等 |
| **能力（Ability）** | 渠道 × 模型的组合，决定某模型请求能被路由到哪些渠道 |
| **令牌（Token）** | 业务方持有的 API 凭证，绑定分组、额度、模型白名单、并发上限 |
| **分组（Group）** | 决定可见模型、可用渠道与计费倍率的用户分组 |
| **计费表达式** | 一行字符串，完整描述某模型的计费逻辑 |
| **倍率** | 传统倍率计费方式下的价格系数（模型 / 完成 / 缓存 / 分组等） |
| **预扣 / 结算** | 请求开始前预扣额度，请求结束后按真实用量结算差额并退款 |
| **任务插件** | 以 JS 插件形态接入的异步长耗时能力（视频、图片、音乐、离线转写） |
| **宿主协议** | 插件声明实现的协议形态（openai_video / openai_image / openai_audio / openai_responses） |
| **产物（Artifact）** | 任务完成后可下载的结果文件或内容 |
| **渠道亲和** | 让符合规则的请求固定命中同一渠道，保持缓存命中与会话一致性 |
| **有效权重** | EWMA 动态计算的渠道权重，让慢渠道自动少分流量 |
| **fail-open** | 依赖组件故障时选择放行并降级，而非拒绝服务 |
| **原子性操作** | 本地调用链中的单次原语；此处指 Lua 脚本一次性完成多桶计数取放 |
| **admin_info** | 日志中仅管理员可见的扩展字段，用户侧自动剥离 |
| **upstream_request_id** | 上游返回的请求 ID，用于与上游账单对账 |
| **superuser 角色** | 无需逐条策略即拥有全部权限的内置角色（root） |

## 2. 常见问题

### 2.1 接入类

**Q：客户端需要改多少代码？**
A：用 OpenAI 兼容协议接入的话，改动只有 `base_url` 与 `api_key` 两处。切换模型只改 `model` 字段。

**Q：Java 客户端能用官方 SDK 吗？**
A：可以。`com.openai:openai-java` 的客户端 builder 提供 `baseUrl(...)`；社区常用的 `com.theokanning.openai:openai-java` 也支持 `new OpenAiService(okHttpClient, timeout, baseUrl)`。若所用版本未暴露该参数，用 OkHttp 直调 HTTP 即可，与 Python SDK 完全等效。

**Q：怎么只让某个部门用某些模型？**
A：建分组，把模型与渠道关联到该分组，再给部门用户的令牌指定该分组。

**Q：模型名写错会怎样？**
A：两类问题，可按错误码区分：

- **无可用渠道承载该模型** → 503 `model_not_found`（同步与异步任务走同一路由逻辑；音频转写端点还会额外点名"该模型未被任何任务插件认领"）
- **渠道侧模型映射缺失或映射链断裂** → 另一个错误码 `channel:model_mapped_error`；未配置映射时模型名会**原样透传**给上游，错误来自上游

排查时先看错误码，再结合上游实际收到的模型名与渠道日志。

### 2.2 计费类

**Q：为什么同一个模型在不同分组费用不同？**
A：分组倍率乘进最终费用，这是有意的内部转移定价机制。

**Q：预扣多了会退回来吗？**
A：会。结算按上游真实用量算，与预扣的差额退回。

**Q：上游返回的用量看起来不对怎么办？**
A：系统会做归一化与饱和处理，不会直接采信异常值。发生截断时日志里会有 `admin_info.quota_saturation` 标记，管理员可查。

**Q：表达式计费和倍率计费能混用吗？**
A：同一模型不能。配置为 `tiered_expr` 的模型走表达式路径，倍率表条目不生效。

**Q：供应商涨价了要改哪？**
A：更新内置表达式或后台覆盖。系统不会自动跟随上游定价。

### 2.3 运维类

**Q：多节点部署要注意什么？**
A：必须共享主数据库、`SESSION_SECRET` / `CRYPTO_SECRET` 与同一个 Redis。**Redis 不共享会导致限流与并发计数按节点独立计算**，实际并发是节点数的倍数。

**Q：可以跟随 `latest` 镜像吗？**
A：不建议。`latest` 会随发布变化，迁移与兼容性需自行评估。从 Releases 固定版本号。

**Q：升级前要做什么？**
A：读发布说明、备份数据库与数据目录、先在预演环境验证。

**Q：流式响应被截断？**
A：检查反向代理是否关闭了缓冲，以及是否配置了流式超时（`STREAMING_TIMEOUT`）。

**Q：WebSocket 连不上？**
A：反向代理需支持 WebSocket 升级，且上游与渠道配置也需兼容。

### 2.4 扩展类

**Q：怎么接一个新的视频生成厂商？**
A：写一个任务插件，声明 `openai_video` 宿主协议，实现 `decodeRequest` 与 `render`，在 `usageSchema` 中声明计费维度。详见 [06-异步任务与插件](06-异步任务与插件.md)。

**Q：插件的计费描述要怎么写？**
A：数值型字段的 `description` 必须命名**计费主体 + 单价**（如 `Video generation unit price` / `视频生成单价`），单位放 `unit` 字段，字段值仍是用量数量。描述要简短、各语言等价、不含数字价格。

**Q：怎么加一个新的计费档位？**
A：写一条计费表达式，如 `len <= 272000 ? tier("standard", ...) : tier("long_context", ...)`。注意长上下文档位对**整个请求**生效。

**Q：怎么加一个新的 OAuth 提供方？**
A：在 `oauth/` 下实现提供方并注册到 `oauth/registry.go`。

| 维度 | 取值 |
| --- | --- |
| 上游供应商 | 40+ |

| 对外转发路由 | 58 条 |
| 控制台模块 | 28 个 |
| 容器平台 | Linux amd64 / arm64 |
