## 这套文档是什么

## 三十秒版

- **它是什么**：自托管的 AI 网关。接上上游模型服务，对客户端暴露一套统一 API，用 Web 控制台管路由、访问、用量和成本。
- **解决什么**：多供应商接入要改代码、成本看不见、单点故障不可控、账号分散难管理——这四类成本它逐项消除。
- **核心能力**：40+ 上游供应商；OpenAI / Anthropic / Gemini / Responses 四套文本协议互转；59 种渠道类型（Web 控制台可选 52 种）；模型映射、优先级权重、多 Key 池、渠道亲和；配额、订阅、兑换码、用量日志；表达式计费；JavaScript 任务插件扩展异步能力；7 语言 Web 控制台。
- **技术栈**：Go 1.25 + Gin + GORM v2 后端，React 19 + TypeScript + TanStack + Tailwind CSS 4 前端；主库 SQLite / MySQL ≥5.7.8 / PostgreSQL ≥9.6，日志库可另配并支持 ClickHouse，缓存用 Redis。
- **适合**：团队内部共享模型访问、私有化多模型服务、多供应商成本归集、需要审计与用量分析的组织。
- **不适合**：面向公网转售 API 的场景（需先完成备案、许可、内容安全、实名、税务等义务）、需要按租户分片的 SaaS 多租户、要求 active-active 多活的场景。

## 事实基准

本套文档描述的是**当前源码树**的实际状态，事实来源为：

- 上游 `README.md` 的产品描述与能力表（权威口径）
- 本仓库源码：`router/`、`relay/`、`relaykit/`、`service/`、`model/`、`setting/`、`plugins/`、`web/`
- `docs/` 下的架构决策记录（`adr/`）、插件 API 规范（`plugin-api/`）与认证指南（`authentication.md`）
- 环境变量参考：根目录 `README.md` 的环境变量表与 `.env.example`（`docs/` 下无独立的环境变量参考文件）

具体版本请以 Releases 的发布说明为准。

> **合规提示**：本项目仅用于合法且已获授权的 AI API 网关、组织级认证、多模型管理、用量分析、成本核算与私有部署场景。使用者须自行依法取得上游 API 密钥、账号、模型服务与接口权限，并遵守上游服务条款与适用法律法规。
