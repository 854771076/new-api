## 结论摘要

| # | 验证目标 | 结果 |
|---|---------|------|
| 1 | 同质渠道负载均分 | ✅ 67 发分布 18/17/16/16,≈25%/渠道 |

| 4 | 退化真值:未配槽位/零权重渠道行为不变 | ✅ 两处均实测复现(见发现 1、2) |

**发现 1(slot 门,计划内设计)**:渠道 `concurrency_limit=0`(未配槽位)时,即使 EWMA 记录已暖(样本 37、延迟 1171ms vs 快渠道 170ms),乘数恒为 1.00——`maybeRecomputeChannelRouting` 的 slot 门(model/channel_routing_health.go:385)按 02-17 计划 D-R1 退化真值执行:"渠道未配槽位→有效权重分量恒等于静态权重"。前两轮实验乘数不动即此因,**非缺陷**。

**发现 2(平滑全 0 分支,同样为计划内)**:配了槽位但静态权重全为 0 时,选路落入 `sumWeight==0 → 各 +100` 平滑分支,乘数被 100 的固定加项抵消,流量分布仍均匀(实验三:乘数 2.00/2.00/1.63/0.50 已分化,但暖机后分布 10/10/9/7 无迁移)。

**运维要点:要让 EWMA 动态调权生效,渠道需同时满足 ①`concurrency_limit`>0(02-14 槽位)②静态 weight>0。** 两者任一不满足则退化为静态均分——这是刻意的降级保真设计,不是 bug。

## 实验记录

### 实验一(同质基线,EXP=homo)

四渠道同配置直连上游。67 发分布 **lb-01:18 / lb-02:17 / lb-03:16 / lb-04:16**(各≈25%),单发耗时全 <1s。负载均分 ✅。

### 实验二(异质,未配槽位,EXP=hetero2)

lb-04 接 +1s 延迟代理。89s、105 发全程 32 个采样点:ch6 latencyEWMA 收敛到 1171ms、快渠道 157-186ms,**四渠道 multiplier 恒 1.00**。流量分布 32/16/20/37,无迁移——因为 `concurrency_limit=0` 触发 slot 门(发现 1),EWMA 不触碰未配槽位渠道。该轮价值:精确隔离出 slot 门的行为边界。

### 实验三(配槽位+权重 0,EXP=hetero3)

四渠道 `concurrency_limit=4`(静态权重仍 0)。乘数开始分化:

```
时间      ch3(lb-01)  ch4(lb-02)  ch5(lb-03)  ch6(lb-04,慢)
02:46:54  n10 m1.00   n14 m2.00   n10 m1.00   n15 m0.57   ← ch4 首先出暖门
02:47:03  n14 m2.00   n18 m2.00   n12 m1.63   n19 m0.40   ← 全员出暖门,均值被慢渠道拉高
02:47:52  n25 m2.00   n29 m2.00   n23 m1.72   n28 m0.50   ← 稳态
```

但暖机后分布 10/10/9/7 **无迁移**——静态权重全 0 触发平滑分支(发现 2)。此轮同时验证了 stale 自愈:hetero3 结束 6.5 分钟后复跑 hetero4,旧记录(>5min)被整丢、从 0 重新播种(时间线 02:54:18→02:54:21 可见 n29→n1),T-02-17-01 自愈路径在生产实测成立。

### 实验四(配槽位+权重 100,EXP=hetero4,完整因果链 ✅)

四渠道 `concurrency_limit=4, weight=100`。时间线关键帧:

```
时间      ch3(lb-01)  ch4(lb-02)  ch5(lb-03)  ch6(lb-04,慢+1s)
02:54:39  n10 m1.00   n11 m1.00   n10 m1.00   n5  m1.00   ← 暖门未全开,全中性
02:54:42  n12 m0.96   n11 m0.98   n11 m1.06   n7  m1.00   ← 仅快渠道出暖门;暖均值≈自身延迟→≈1
02:54:51  n17 m2.00   n15 m2.00   n14 m2.00   n10 m0.50   ← ch6 出暖门,均值被 1178ms 拉高:
                                                              快渠道 469/163=2.9→钳 2.00
                                                              慢渠道 469/1178=0.40→抬 0.50
02:55:37  n28 m2.00   n37 m2.00   n26 m2.00   n14 m0.50   ← 稳态
```

流量分布(按发压阶段):

| 阶段 | n | lb-01 | lb-02 | lb-03 | lb-04(慢) |
|------|---|-------|-------|-------|-----------|
| 暖机 A(乘数≈1) | 64 | 28% | 31% | 25% | 16%(噪声内,χ²=3.5 p≈0.32) |
| 暖机后 B+C(乘数 2/2/2/0.5) | 41 | 27% | 41% | 24% | **10%** |

理论有效权重:快 100×2.00=200、慢 100×0.50=50 → 慢渠道份额 **50/650=7.7%**,实测 B 阶段 3/36=**8.3%**、B+C 合计 4/41=9.8%,命中。首次选路渠道计数(105 发):ch3:28 / ch4:37 / ch5:26 / ch6:14——慢渠道被自动边缘化,同时未饿死(下限 0.2 保证可选)。

因果链逐环:延迟观测(1178 vs 163ms)→ warm 门(≥10 样本)→ latencyFactor=clamp(暖均值/本记录, 0.5, 2.0) → 乘数 clamp(…, 0.2, 5.0) → 有效权重=静态×乘数 → 加权随机抽取 → 慢渠道份额 25%→8%。**全部环节与 02-17 计划公式逐值吻合**(稳态 2.00/0.50 即钳制上下界,1.63/1.72 为均值随记录数移动的中间值)。
